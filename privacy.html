Privacy Policy

Music Channel Tools
Last updated: October 15, 2026

Who uses this app

Music Channel Tools is a private application used only by the owner of the YouTube channel "The Music Channel". It is not offered to the public, and it only accesses the owner's own Google/YouTube account.

What data it accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API and YouTube Analytics API to access the owner's own channel: channel and video details, video statistics and analytics, playlists, and live stream and live broadcast settings.

How the data is used

The data is used only to operate and manage the owner's own channel: keeping the channel's 24/7 live stream online, reading performance statistics, and updating the owner's own videos, thumbnails and playlists.

Storage and sharing

The OAuth access token is stored only on the owner's private server. Data retrieved from YouTube is used on that server for the purposes above. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Music Channel Tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
